# 工作看板 · kanban-desk

面向个人与小团队的桌面工作台：**看板 + 白板 + 文档**三合一，一个项目一个文件夹，数据全在本地。

> 为建筑室内设计这类「边想边画边写」的工作流做的：任务、脑图、参考资料、方案文档放在同一个项目里，
> 看板上的任务和白板上的卡片是同一份数据，改哪边都同步。

## ✨ 核心亮点（v0.7）

**🤖 同时跑四五个 AI 任务** —— 点「发送到 AI」**点完就返回**，不等它跑完；关掉面板任务照跑。
右下角一个圆形「AI」按钮收着全部任务：数字是正在跑的数量，点开是列表，
点一条就展开它的回复、产物和日志。再点同一个任务的 AI，**接回原来那一轮**，
没跑完继续看进度，跑完了显示「上次跑于 …」。
→ [指南 · 右下角的 AI 按钮](docs/使用指南.md#9-给-ai-的指令)

**🎭 角色卡 + 开工规矩 + 缺口授权** —— 每个项目填一次「角色卡」，之后所有任务的指令都自带
**【你的角色】**；再加**【开工规矩】**（不复述指令、先列计划、必须真写文件）治 AI 的两个老毛病；
指令里的信息缺口不再让它停下来追问，而是**授权它按最合理假设照常交付、把补出来的判断标成「假设：…」**。
→ [指南 · 先填一次角色卡](docs/使用指南.md#9-给-ai-的指令)

**🔗 端口即方向，不画箭头** —— 所有节点（便签 / 文字 / 导图 / 分组框 / 图片 / 文档卡 / 甘特卡）
统一**左端口出、右端口进**，连线永远「子左 → 父右」。线上不画箭头——方向已经由端口定死，
画面干净一大截；导出 PNG / PDF 时端口控件会被去掉，所以**导出会自动在线的两头各补一个小圆点**。→ [指南第 6 节](docs/使用指南.md#6-白板)

**🌳 多父层级** —— 一个子任务可以同时服务多个上级，不用复制卡片；交给 AI 的指令会列出全部上级。→ [指南第 6 节](docs/使用指南.md#6-白板)

## 功能总览

**AI 协作**
- 本机 AI 命令行（OpenCode / DeepSeek Harness / Gemini / Claude / Codex）直连，ACP 协议
- 指令不是模板：任务说明、材料档位、关注重点、白板思路、上下级关系全部自动读进去
- **运行池**：多任务并发、后台不中断、随时接回
- **交付格式**新增 **图表 SVG**——让它用 SVG 代码画流程图 / 图表 / 示意图，矢量、可改字、不失真
- **材料与产物可审核**：待审 / 通过 / 打回三态。标「通过」的，指令里会写「已人工审核确认」；
  标「打回」的，整条**不会进指令**，AI 拿不到它就不会照着错的做
- 详见[指南 · 给 AI 的指令](docs/使用指南.md#9-给-ai-的指令)

**看板**
- 列 / 任务 / 优先级 / 标签 / 截止日期，拖拽排序；回收站可恢复
- 下方甘特图：滚轮缩放时间轴、中键平移、拖动条形两端改起止日期、点条配色
- 详见[指南 · 看板](docs/使用指南.md#4-看板) / [指南 · 甘特图](docs/使用指南.md#5-甘特图)

**白板**
- 便签 / 文字 / 思维导图 / 分组框 / 图片 / 文档卡 / 甘特卡，节点间连线即层级
- 七种节点**都有端口**，左出右进，线上无箭头
- 分组框：框内节点自动成组，框头可标材料强度（强依据 / 参考 / 弱参考 / 产物）
- 关系不许成环：下级支撑上级随便连，直系反向会被直接拦住
- 详见[指南 · 白板](docs/使用指南.md#6-白板)

**文档**
- Markdown 所见即所得（Vditor 本地化，离线可用）；正文底色可换，字色自动适配
- 落成真实 `.md` 文件，插图内嵌不丢；导出 Word / Markdown
- 详见[指南 · 文档](docs/使用指南.md#7-文档)

**浮动网页**
- 真浏览器（系统内核，不是 iframe）：禁止嵌入的站点也能开，登录状态保留
- 详见[指南 · 浮动浏览器](docs/使用指南.md#8-浮动浏览器)

**导出**
- 看板：PNG 长图 / PDF / HTML / Word / Markdown；白板：PNG / 单页 PDF；文档：Markdown / Word
- 导出和屏幕一模一样——弧线、端口圆点、配色不走样
- 详见[指南 · 导出](docs/使用指南.md#11-导出)

**数据**
- 一个项目 = 一个文件夹；可整体迁移；全自动保存
- **每天自动备份**：每次启动把各个库拍一份快照到 `备份/<日期>/`，留最近 7 天，更早的自动清掉。
  后端启动时直接做，不占开机时间，也不依赖界面是否加载成功
- 详见[指南 · 项目与数据](docs/使用指南.md#3-项目与数据)

## 技术栈

Vue 3 + TypeScript + Pinia + Element Plus + Vite + Tauri 2（Rust）+ SQLite（rusqlite）

## 开发

```bash
cd app
npm install
npm run tauri dev      # 桌面版（默认 1420 端口）
npm run dev            # 只跑前端，浏览器打开验证界面
```

> 编辑器资源：`npm install` 之后如果 `app/public/vditor` 缺失，执行
> `node scripts/sync-vditor-assets.mjs` 重新同步（离线化必需，请勿改成 CDN）。

## 构建

```bash
cd app
npm run tauri build -- --no-bundle     # 产出单文件 exe
# app/src-tauri/target/release/kanban-desk.exe
```

Windows 上分发注意：产物 **不含 WebView2 运行时**。Win11 自带；Win10 若双击没反应，
需要先装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
可执行文件未签名，首次运行会被 SmartScreen 提示。

## 数据存放在哪

默认在 `%APPDATA%\com.kanban.desk`（macOS/Linux 对应系统的应用数据目录）：

```
项目列表.db                项目清单 + 偏好
备份/<日期>/               每天自动快照（留 7 天）
<项目名>/
  看板与白板.db            这个项目的任务、列、白板节点与连线
  附件/                    上传的资料原件（保留原文件名）
  文档/                    文档正文，真 .md 文件
  AI产出/<任务>/            给 AI 的工作目录：brief.md + refs/ + out/
```

侧栏底部「数据存储」里可以查看当前位置、打开文件夹、换一个位置（会整体迁移）。
备份就**整个目录一起拷**：只拷数据库会丢附件。

## 关于浮动浏览器

界面里有一个可拖动/缩放的悬浮窗口，它就是一个**通用网页浏览器**：地址栏输网址就打开，
输一句话就走搜索；中文域名也能直接识别。内容区用的是系统内核的独立网页视图，
所以像豆包、Bing 结果页这类用 `X-Frame-Options` / CSP 禁止被嵌入的站点也能正常打开，
在结果页点链接会直接在当前窗口里跳转，登录状态也会保留。

项目**不预置任何第三方网站入口**，也不隶属于任何第三方服务。
少数网站可能因自身策略拒绝在非浏览器环境运行，点标题栏的 `↗` 用系统浏览器打开即可；
使用时请遵守所访问网站自身的服务条款。
