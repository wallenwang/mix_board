# 工作看板 · kanban-desk

面向个人与小团队的桌面工作台：**看板 + 白板 + 文档**三合一，一个项目一个文件夹，数据全在本地。

> 为建筑室内设计这类「边想边画边写」的工作流做的：任务、脑图、参考资料、方案文档放在同一个项目里，
> 看板上的任务和白板上的卡片是同一份数据，改哪边都同步。

📖 **第一次用？先看 [使用指南](docs/使用指南.md)** —— 安装、分屏、白板分组框、甘特手势、
文档插图、数据备份与快捷键速查都写在里面。

## 功能

**看板**
- 列 / 任务 / 优先级 / 标签 / 截止日期，拖拽排序
- 任务卡上直接看进度与到期紧迫度（逾期红、3 天内橙、7 天内黄）
- 下方甘特图：滚轮横向缩放时间轴、中键平移、拖动条形两端改起止日期
- 甘特条可点击手动配色（紧急任务标红），不选则按截止日期自动分档
- 回收站，删除可恢复

**白板**
- 便签 / 文字 / 思维导图 / 分组框 / 图片 / 文档卡 / 甘特图节点，节点间可连线
- 导图支持 Tab 加下一级、Enter 加同级；连线的父子关系就是导图层级
- 分组框是「分区」：框内节点自动成组，拖框整区移动；框色可自定义
- 连线支持直线 / 弧线切换；节点形状、便签圆角与配色可调
- 从节点端口拖到空白处，直接弹出「新建什么节点」
- 白板可导出 PNG / PDF

**文档**
- 内置 Markdown 所见即所得编辑器（Vditor，资源本地化，离线可用）
- 文档落成真实的 `.md` 文件，Typora / VS Code 可直接打开
- 正文底色可切换（默认护眼绿），字色随底色自动适配
- 支持插入本地图片，也支持把白板上的图片一键「发送到文档」
- 插图内嵌在 `.md` 里；大文档（图片几 MB）打开也不卡
- 导出 Word（.docx）/ Markdown（Word 目前不含图片）

**数据**
- 一个项目 = 一个文件夹：项目库、附件、文档各归各位
- 可随时更换数据存放位置，整体迁移，旧位置保留不删
- 全自动保存，没有「保存」按钮

## 技术栈

Vue 3 + TypeScript + Pinia + Element Plus + Vite + Tauri 2（Rust）+ SQLite（rusqlite）

## 开发

```bash
cd app
npm install
npm run tauri dev      # 桌面版（默认 1420 端口）
npm run dev            # 只跑前端，浏览器打开验证界面
```

> 编辑器资源：`npm install` 之后如果 `app/public/vditor` 缺失，执行
> `node scripts/sync-vditor-assets.mjs` 重新同步（离线化必需，请勿改成 CDN）。

## 构建

```bash
cd app
npm run tauri build -- --no-bundle     # 产出单文件 exe
# app/src-tauri/target/release/kanban-desk.exe
```

Windows 上分发注意：产物 **不含 WebView2 运行时**。Win11 自带；Win10 若双击没反应，
需要先装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
可执行文件未签名，首次运行会被 SmartScreen 提示。

## 数据存放在哪

默认在 `%APPDATA%\com.kanban.desk`（macOS/Linux 对应系统的应用数据目录）：

```
项目列表.db                项目清单 + 偏好
<项目名>/
  看板与白板.db            这个项目的任务、列、白板节点与连线
  附件/                    上传的资料原件（保留原文件名）
  文档/                    文档正文，真 .md 文件
```

侧栏底部「数据存储」里可以查看当前位置、打开文件夹、换一个位置（会整体迁移）。
备份就**整个目录一起拷**：只拷数据库会丢附件。

## 关于浮动浏览器

界面里有一个可拖动/缩放的悬浮窗口，它就是一个**通用网页浏览器**：地址栏输网址就打开，
输一句话就走搜索。项目**不预置任何第三方网站入口**，也不隶属于任何第三方服务。

需要说明两点：
- 部分网站会用 `X-Frame-Options` / `CSP frame-ancestors` 拒绝被嵌入，表现为白屏，
  点窗口里的 `↗` 用系统浏览器打开即可；
- 使用时请遵守所访问网站自身的服务条款。
